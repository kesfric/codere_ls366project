# NetTango Emoji Trail

A small [NetLogo](https://ccl.northwestern.edu/netlogo/) model built for LS/CS 326/426, using [NetTango](https://www.nettango.org/) blocks for part of the movement logic.

## What it does

- A single turtle starts in the top-left corner of a checkerboard grid.
- You steer it with on-screen arrow buttons (⬅️ ⬆️ ➡️ ⬇️).
- As it moves, it paints a trail whose color depends on which emoji is selected: ❤️ red, 🧡 orange, 💛 yellow, 💚 green, 💙 blue, 💜 violet.

## Running it

1. Install [NetLogo](https://ccl.northwestern.edu/netlogo/download.shtml) (version 7.0.x).
2. Open `draft 1.nlogox` in NetLogo.
3. Click **setup**, then use the movement buttons to draw.

## Notes

Part of this model's code was generated by the NetTango Web Builder (see the `NETTANGO BEGIN/END` block in the code) and then hand-edited directly in NetLogo.
